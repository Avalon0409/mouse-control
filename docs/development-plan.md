# 实施与验证记录

## 已接入

- 雷蛇设备控制、DPI 档位、按键、本地配置及按应用切换配置。
- 鼠标/触控板独立滚动、水平规则、固定步长、平滑和速度调整。
- 普通 HID 鼠标列表与基础配置，设备移除/恢复保留配置。
- 有效序列号跨 USB/蓝牙共享配置；后台保留原始连接，界面显示一个物理设备与当前连接方式。
- USB 身份缓存按系统启动会话及 USB 物理节点实例保存，拔插后重新验证，防止同一端口上的不同鼠标误继承身份。
- 快捷键宏、低电量提醒、系统电池来源观察/补充、配置导入导出。
- 中文/英文、系统浅色/深色、鼠标/可达鸭图标及菜单栏档位切换。
- 自有 GitHub Release 更新检查、更新包签名、Git 标签与提交号写入发布包。

## 验证

2026-11-02 的测试覆盖协议解析、型号能力、配置迁移、蓝牙 UUID 路由、物理设备合并、连接切换、普通鼠标能力、移除/恢复、滚动规则跨进程同步、语言、图标和更新版本选择。

实机使用 Orochi V2 蓝牙及 2.4 GHz 接收器、Dell MS116 USB 鼠标和内建触控板：

- Orochi 两种连接读回的私有序列号相同。切换后保持一条设备，连接标签跟随可用连接；应用重启后随身份解析完成合并。
- Orochi DPI、回报率、休眠逐项写入、读回、恢复通过；用户手动调整的最新参数保持。
- Orochi 的五档指示色按官方手册为红、绿、蓝、青、黄。
- 独立滚动方向已实测；同一 Orochi 的跨连接规则合并并持久化。Dell 独立规则保留，触控板使用自然方向。
- Dell 出现在主设备列表，提供固定一档与系统指针速度入口；列表移除及恢复保留配置。
- 固定开发证书下，多次重建与重启保持输入监控和辅助功能授权身份。
